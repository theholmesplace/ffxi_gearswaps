# FFXI GearSwap LUAs

GearSwap files for the character Treasurehider, copied from
`Windower/addons/GearSwap/data/Treasurehider`.

To use them, copy the files in `Treasurehider/` back into that folder in your Windower install.

- Main jobs: DRK, GEO, DNC, THF, RUN, PLD, BLM
- Also included: RDM, SCH, WAR, shared `*_Lib.lua` libraries, `Treasurehider-Globals.lua`, and older `_BACK` backups
